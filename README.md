# HYMN · site

Site da HYMN, agência criativa com estúdio e produtora dentro de casa.

## Como ver

Abra o `index.html` no navegador. Não precisa instalar nada: é HTML, CSS e JavaScript puros.

## O que tem aqui

- `index.html`: a home (abertura, faixa, claquete das três frentes, trabalhos, clientes e contato).
- `tokens.css`: cores, fontes, espaços e tempos de animação da marca.
- `componentes.css`: botões, selos e peças reaproveitáveis.
- `assets/`: logo, imagens e fotos. As imagens da pasta `exemplos/` são provisórias e saem quando chegarem os trabalhos reais.
